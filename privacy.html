Privacy Policy

Rclone Personal Drive is a personal Google Drive integration using Rclone.

Data Access

The application accesses Google Drive files only with the account owner's authorization.

Data Usage

Data is used to browse, upload, download, organize, and synchronize files across authorized Google Drive accounts.

Data Storage and Sharing

OAuth credentials are stored locally by Rclone. File transfers are initiated by the user. Data is not sold or used for advertising.

Revoking Access

Access can be revoked through Google Account security settings.
